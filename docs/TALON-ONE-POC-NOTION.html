TechStore × Talon.One PoC 정리

프로젝트: TechStore (Next.js 데모 쇼핑몰)
목적: Braze(발급·CRM)와 역할을 분리한 Talon.One 프로모션·쿠폰·세션 PoC
환경: Talon.One Live Application TechStore (KRW)
작성: 2026-08-06

1. PoC 한 줄 요약

장바구니/체크아웃에서 Talon.One Integration API로 세션을 평가하고, Dashboard 캠페인(C1~C3)에 따라 할인·쿠폰·멤버십 보너스를 실시간 반영한다. 주문 완료/취소 시 세션을 closed / cancelled로 마감한다.

2. 역할 분리 (Braze vs Talon.One)

레이어담당PoC에서 한 일
Braze쿠폰 발급, 메시징, 배너, external_id기존 유지. 로그인 시 changeUser(email)
Talon.One할인 규칙, 쿠폰 검증/적용, 로열티C1~C3 캠페인 + 세션 API
TechStoreUI, BFF API, 주문/api/v1/talon/session, 카트/체크아웃 UI

핵심: 카탈로그 SALE 뱃지 ≠ Talon 할인. PoC에서는 목록은 정가만, 할인은 장바구니에서 Talon이 평가.

5. 테스트 시나리오

C1 — 5만원 이상 10% (비로그인 OK)

  • 5만원 미만 → 할인 0원
  • 5만원 초과 → 10% 할인

C2 — WELCOME10 (비로그인 OK)

  • 5만원 이상 + WELCOME10 적용
  • 제거 시 C1만 유지

C3 — GOLD 5% (로그인 필요)

  • /login → GOLD
  • SILVER는 C3 없음

풀 데모 (15분)

  1. GOLD 로그인
  2. 5만원 이상 담기 → C1 + C3
  3. WELCOME10 → C1 + C2 + C3
  4. 주문 → talon_session_closed
  5. (선택) 취소 → talon_session_revoked

8. Integration API vs Management API

PoC는 Integration API만 사용. 라이선스 고객의 초기 Import·백오피스는 주로 Management API(또는 Campaign Manager UI).

8.1 역할 도식

┌─────────────────┐     Integration API      ┌──────────────────────┐
│  쇼핑몰 / BFF    │ ───────────────────────► │  Talon.One Engine     │
│  (TechStore)     │  실시간 세션·프로필·효과   │  (할인 평가)          │
└─────────────────┘  ApiKey-v1               └──────────────────────┘
                                                      ▲
┌─────────────────┐     Management API               │
│  백오피스 / 배치  │ ───────────────────────► │  Campaign Manager    │
│  CRM / 마이그    │  쿠폰·로열티 Import, 캠페인 │  (설정·Import)       │
└─────────────────┘  ManagementKey-v1        └──────────────────────┘
Integration APIManagement API
한 줄고객·카트 실시간 연동Campaign Manager를 코드로
주요 용도세션 평가, 쿠폰 적용, 주문 close쿠폰/로열티 Import, 캠페인·속성 관리
호출 주체쇼핑몰 BFF, 체크아웃배치 잡, 어드민, 마이그레이션
인증ApiKey-v1ManagementKey-v1
부하·SLA실시간·고부하 (계약 SLA 대상)백오피스 (~3 req/s)
PoC에서사용 (/api/v1/talon/session)미사용

8.2 작업별 API 선택

작업API
장바구니 할인 평가 / 주문 close·cancelIntegration
고객 프로필 속성 / 과거 주문 적재Integration
쿠폰 CSV Import / 로열티 포인트·카드 ImportManagement
쿠폰 대량 생성 (발급 연동)Management
캠페인 규칙 설계Dashboard (또는 Management) — 레거시 1:1 자동 이관 없음

주의: Management API를 카트/체크아웃 경로에 쓰지 말 것. 실시간 평가는 항상 Integration API.

9. 실제 도입 시 초기 Import / 마이그레이션

PoC(C1~C3)는 그린필드라 Import가 없어도 된다. 기존 Incentive·쿠폰·로열티를 이어 쓰는 Go-live라면 아래가 검토 대상이다.

PoC (현재)라이선스 고객 초기 세팅

기존 쿠폰WELCOME10만레거시 코드 bulk import
로열티 잔액프로그램만 생성포인트/카드 잔액 import
고객·구매 이력세션 평가만프로필·과거 session 적재
데이터API방식

이관 가능: 쿠폰 코드·로열티 잔액·프로필·과거 주문
재설계 필요: 프로모션 규칙 엔진 로직 (1:1 자동 이관 없음)

한 줄: 실시간 할인 = Integration API (PoC). 초기 Import = Management API + (프로필/이력은) Integration 배치. 레거시 규칙은 Talon Campaign으로 재설계.
